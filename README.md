# 🌐 Reale Mutua Website Simulation – Phase 1

This repository contains the **first phase** of a multi-stage front-end development project. The goal of this phase is to **simulate the current Reale Mutua website**, serving as a foundational step in my journey toward becoming a Full Software Developer. It includes responsive design, interactive UI features, and mock authentication workflows.

**You are welcome to explore and test the web version of this simulation directly online**—no need to download the project. You can check its **responsiveness, design, and user experience** by following the link provided below in the [🔗 Live Demo](https://artembulgakov-git.github.io/reale-mutua-simulation/) section.

---

## ✅ Achievements

* Recreated pages of the Reale Mutua website using semantic, accessible **HTML5**.
* Designed a **responsive layout** using CSS3 with a mobile-first approach.
* Integrated **JavaScript interactivity** (form validation, menu toggles, etc.).
* Simulated a **login system** using the DummyJSON API and JWT-like token logic.
* Laid the groundwork for transitioning to a fully dynamic front-end architecture.

---

## 🛠️ Technologies Used

* **HTML5** – Semantic structure and accessibility
* **CSS3** – Responsive layout, media queries, CSS variables
* **JavaScript (ES6+)** – Interactivity and logic handling
* **REST API** – DummyJSON used for mock authentication
* **Git & GitHub** – Version control and collaboration

---

## 🚀 Key Features

* Fully responsive and accessible interface
* Token-based mock authentication (JWT logic simulation)
* Progressive enhancement approach
* Modular and maintainable codebase
* Design inspired by the original Reale Mutua site aesthetics
